# Finger Organ
Play organ chords with your fingers in front of the webcam.

- Live: https://gabiwan24.github.io/airpiano/
- Local: double-click `start.bat`, then click **Kamera & Ton starten**.
- Fingers of both hands added up, 1–10 = chords on every scale step: I ii iii IV V vi vii° (1–7), I ii iii an octave higher (8–10). Fists = silence.
- Variant (triad · 7 · sus4 · sus2 · add9 · major↔minor) and key: by click.
- After each chord the app shows which chords fit next (functional harmony).
- Hand height = volume (swell). Space = mute / unmute. Without a camera: keys 1–9, 0 = 10.
- Tests: `npm test`
